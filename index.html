ProjectsProjets

biblio1-api

Java 21 · Spring Boot 4 · Spring Data JPA · Docker · GitHub Actions

A layered REST service for managing a library: books, authors, members and loans. Paginated and sortable collections, criteria-based search, per-operation DTOs, validation on every input, and a global exception handler that turns business errors into accurate status codes with a JSON body naming each invalid field. Three configuration profiles, a health endpoint, and a multi-stage Docker build.

Un service REST en couches pour gérer une bibliothèque : livres, auteurs, membres et emprunts. Collections paginées et triables, recherche par critères, DTO par opération, validation de toutes les entrées, et un gestionnaire d’exceptions global qui traduit chaque erreur métier en code HTTP exact, avec un corps JSON nommant les champs fautifs. Trois profils de configuration, un point de surveillance et une image Docker en deux étapes.

Hébergement gratuit : le premier appel réveille l’instance et prend environ une minute. La base est en mémoire et repart vide après chaque redémarrage.
